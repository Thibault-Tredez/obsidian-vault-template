# Idées

Idées brutes, capturées telles quelles dès qu'elles traversent l'esprit — non triées.

Une fois mûrie, une idée est déplacée :
- vers `Clients/<client>/` si elle concerne un client précis
- vers `Ressources/` si elle devient une méthode ou solution réutilisable
- ou transformée en projet via le template `note-projet`
