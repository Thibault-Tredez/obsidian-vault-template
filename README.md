# Vault de départ

Structure de base pour un vault Obsidian synchronisé automatiquement avec Claude Code.

- `Clients/` — un dossier par client
- `Idées/` — idées brutes, non triées
- `Ressources/` — méthodes et solutions réutilisables
- `Templates/` — modèles de notes (Templater)
- `setup.sh` — script d'installation automatique du serveur (voir le guide fourni)
